# Tutorial bug repairs (Dolphin report, 2026-11-01)

| Bug | Root cause | Fix | Regression test |
|---|---|---|---|
| 1. Screen shakes while reading signs | Signs with a camera target (Start -> `sign2`, `othercamcenter`) moved the camera twice a frame: the normal follow-Mario step (with the CamEdge push) and the target step, which ignored CamEdge. Near an edge the push undid the target move every few frames (11 px jumps). | One camera move per frame: `course_camera_step_to` moves toward the target with the original CamEdge limits (`camXspeed = -(Camcenter)/Camspeed`); following Mario is skipped while a target is set. | `test_sign_camera_steady` (no reversals over 400 ticks, smooth return) |
| 2. Wrong fish animation | The turn clip's frame-4 script (`_parent._parent.frame = "swim"`) was missing, so a Cheep Cheep froze in its turn pose after its first turn. Its rotation was negated when mirrored, though Flash composes `_rotation` after the `_xscale` mirror. A new label did not restart its clip. | Turn returns to swim on frame 4, labels restart their clip, rotation drawn as is (the spin clip's inner rotation reverses under the mirror). | `test_cheep_animation` |
| 3. Triple jump, backflip, dive flips | (a) The takeoff tick still touches the ground, which reset the jump chain, so every jump was a first jump. (b) The stand-up check tested 4 px above the feet at x+/-8, so on any slope it failed and no crouch backflip or diveflip could start (the tutorial is mostly slopes). (c) Backflips and diveflips ended on that same takeoff tick and diveflips lasted 22 frames, blocking the air dive. | Jump chain follows `doublejump`/`doublejumpcount` (9 ground frames, JumpPress buffer 7 frames); triple jump at 1.5x the first jump with `xspeed -= (xspeed -/+ 15)/5`; stand-up clearance checks above the crouch height; diveflip ends at Diveflip.xml frame 8, backflip at frame 21 or on landing from frame 14 (`air == false && yspeed > -3`), with the dive and ground pound available as the clips allow; diveflip uses the ground angle (< 25 degrees). | `test_triple_jump_chain`, `test_crouch_backflip_on_slope`, `test_dive_flip_chain` |
| 4. Toad invisible | Trimmed object frames added image pixels (1.6 per course px) to an offset in course twips, and FFDec pads the PNG canvas around filters (Toad's head) while the origin came from the unpadded SVG. Toad was drawn about 30 px low, inside the ground. | `build(..., px_twips = 20 / zoom)` and the origin corrected by half the PNG padding. Every object frame is now placed exactly (most were off by under 1 px). | `tests/test_object_art.py` |

Notes: the second jump in a chain at walking speed below 3 px/frame is, in the
original, a press that does nothing (`doublejump == 2` without the speed); the
port starts a new first jump instead. Walking/running acceleration still uses
the port's model, not CharCode's.
