## Physics/control corrections (commit 1)

- `DOMDocument.xml:5540–5610,6000–6050,6150–6168,6265–6290`:
  water detection uses the feet minus one quarter of the collider height;
  deep-water gravity is 1/3; resistance layers are 0.05/1.01, 0/1.001, then
  0.05/1.1 vertically and 0.05/1.05 horizontally. Up begins a -6 impulse
  (-4 while Down is also held), then sustains -0.2 per source frame; Down adds
  +0.3. A new impulse requires release after more than five source frames.
  Water entry damps high downward speed by 0.7 then all vertical speed by 0.9.
  The source's left-entry `xpseed` typo is retained (no mirrored +2 impulse).
- `Char/Mario CLIPS/Mario Main.xml` frame `Spin` initializes speed 15.
  `Mario (none) Spin Attack.xml` supplies the exact speed decay, sqrt lift,
  vertical drag, Down acceleration and ground/air stop thresholds 5/3.
  `DOMDocument.xml:5966` permits spin initiation only above vertical speed -3;
  an active spin cannot be refreshed by pressing X. Held X can start a new
  attack after the previous one ends. Rapid alternating directions boost speed
  with `speed*0.8+15`, rather than an arbitrary unlimited upward impulse.
- `Mario (None) Dive.xml:145–177`: backflip starts from a slow grounded dive
  with Up opposite the stored facing. Preserve the actual backward impulse
  `(0.75*vx) - ((0.75*vx)-target)/5`, target opposite facing at 30 source units.
  `Mario Backflip.xml` lasts 22 source frames; its control does not flip facing.
  Slow Down+Up does not invent the v0.4 forced forward roll; forward recovery
  requires speed >3, clip frame >2, and a non-sloped floor.

These recurrences now run on a 32 Hz source clock nested in fixed 60 Hz updates.
Collision and position integration remain 60 Hz, and ordinary land-jump tuning
is retained. This is a documented adaptation, not proof of identical trajectories
or script execution ordering. Tests compare recurrence values and timing,
including repeat spins, finite fall, water strokes and both backflip directions.
No Dolphin/original-game side-by-side verification has been performed here.
